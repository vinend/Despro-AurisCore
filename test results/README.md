## Python test coverage

The 25 passing tests cover:

- Atomic dataset acquisition and checksum-change detection.
- Audio loading, mono conversion, resampling from 4 kHz, 8 kHz, and 44.1 kHz, segmentation, filtering, MFCC feature shape, silence, clipping, corrupt/empty/non-finite input handling.
- Deterministic participant-level splitting, repeated IDs, conflicting labels, manifest validation, unknown-label exclusion, duplicate leakage prevention, bad/orphan file handling, and silent-quality exclusion.
- Sensitivity-first threshold selection and protection against relabelling an exposed holdout as fresh.
- CNN input/output shape.
- End-to-end synthetic SVM and log-mel CNN training, artifact creation, holdout locking, and one-time evaluation.
- An actionable error when the dataset is missing.

Pytest emitted 32 dependency deprecation warnings: 14 from Matplotlib/pyparsing and 18 from Keras/NumPy compatibility paths. They did not fail the run, but future library upgrades may turn some of them into errors. The exact warning text is retained in `logs/ai-pytest.log`.

## Reproducing the core suite

From the repository root in PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File ".\test results\run_all_tests.ps1"
& ".\AI-Pipeline\.venv\Scripts\python.exe" ".\test results\collect_results.py"
```

The runner expects `AI-Pipeline/.venv` with the CNN requirements already installed and existing `node_modules` directories for the WebApp and mock device. The two live runtime JSON files document this run; they are not currently regenerated by the core runner.

## Interpretation and next test

The repository is functionally healthy under the tested environment, and the 8 kHz contract is internally consistent from configuration through the live mock stream. The next meaningful model test requires a genuinely untouched, participant-separated set of real 8 kHz device recordings with labels hidden until the CNN architecture, preprocessing, and threshold are frozen. Until then, the model remains research-only.
